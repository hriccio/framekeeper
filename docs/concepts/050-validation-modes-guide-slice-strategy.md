# Validation Modes Guide Slice Strategy

Validation mode is a practical guide for how a slice should be validated.

## Meaning

Some slices are best checked headlessly, some benefit from interaction, and
some need lived interaction to reveal expectation gaps. The mode should guide
the slice strategy instead of being discovered too late.
