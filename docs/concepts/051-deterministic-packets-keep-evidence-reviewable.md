# Deterministic Packets Keep Evidence Reviewable

Evidence is easier to review when it lives in a compact deterministic packet.

## Meaning

Scenario review works best when the packet contains the domain context, the
contract summary, the scenario steps, and the captured outputs in a form that is
easy to inspect.
