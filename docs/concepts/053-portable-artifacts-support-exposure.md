# Portable Artifacts Support Exposure

Exposure works best when the accepted state has a portable form.

## Meaning

If an artifact is going to be exposed, it should be packaged in a form that can
travel into the real context without depending on the internal loop around it.

## Related Episodes

- [Release Decisions Stay Explicit](../episodes/050-release-decisions-stay-explicit.md)
- [Exposure Follows Acceptance](../episodes/051-exposure-follows-acceptance.md)

## Notes

- keep the exposed artifact portable
- make the released version easy to identify
- expose the accepted state, not the whole internal workflow
