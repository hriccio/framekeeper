# Requests Are Review Units

Requests should be reviewed as bounded units.

## Meaning

The request is the boundary for expectation review. Slices and implementation
artifacts support that review, but they do not replace the request itself.

## Notes

- keep the request explicit
- review the request as the unit of intent
- avoid letting implementation rewrite the goal
