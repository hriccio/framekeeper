# Slice Docs Keep Build Bounded

Slice docs keep implementation work bounded and legible.

## Meaning

Each slice should say what it covers, what evidence it should produce, and
which part of the request it is intended to satisfy.

## Notes

- slice docs are a control surface for build work
- they keep build scope narrow
- they should not become implementation code
