# Archival Pages Stay Linked

Archived pages should remain linked from the active site whenever they still
help the reader.

## Meaning

If a page is archived but still relevant, it should not become hard to find. The
site should keep its path visible so the history remains connected.

## Notes

- keep archival pages reachable
- preserve the trail back to older thinking
- avoid treating archived material as invisible
