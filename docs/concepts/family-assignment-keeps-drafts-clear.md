# Family Assignment Keeps Drafts Clear

Candidate ideas are easier to shape when they already point to a page family.

## Meaning

Family assignment reduces ambiguity. A draft that knows whether it is heading
toward an episode, concept, reference, or note is easier to edit and easier to
review.
