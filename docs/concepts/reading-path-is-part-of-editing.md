# Reading Path Is Part Of Editing

Editing includes deciding what path a reader is likely to take.

## Meaning

A page is not only what it says. It is also how it leads the reader to the next
useful place. That path should be designed intentionally.

## Notes

- keep the route intentional
- make supporting material discoverable
- do not leave the reader guessing about the next step
