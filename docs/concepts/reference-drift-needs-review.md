# Reference Drift Needs Review

References can drift out of date even when the page text still looks stable.

## Meaning

When a source moves, changes, or becomes less representative, the page should
be reviewed. Drift is a maintenance problem, not a minor detail.

## Related Episodes

- [Sources Need Refresh Cycles](../episodes/032-sources-need-refresh-cycles.md)

## Notes

- check whether the source still supports the claim
- refresh references when context changes
- keep the page honest about time-sensitive material
