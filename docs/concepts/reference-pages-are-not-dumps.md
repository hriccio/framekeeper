# Reference Pages Are Not Dumps

Reference pages should stay selective and useful.

## Meaning

A reference page is not a place to collect every possible link. It exists to
support the ideas and pages that need those sources.

## Notes

- keep the list curated
- remove links that no longer help
- prefer relevance over volume
