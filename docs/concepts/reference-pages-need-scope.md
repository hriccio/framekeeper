# Reference Pages Need Scope

Reference pages work best when they stay focused on a clear supporting role.

## Meaning

A reference page should make a specific source or policy easy to find without
trying to become an encyclopedia. Scope keeps the page useful and maintainable.

## Notes

- keep reference pages narrow
- use them to support claims or context
- avoid turning them into source dumps
