# Review And Block Are Distinct

`REVIEW` and `BLOCK` should not be blurred together.

## Meaning

Review is a checkpoint for human judgment. Block is a stop state. Keeping them
distinct preserves the meaning of the safety path and makes the workflow easier
to read.

## Notes

- keep the states separate
- do not use review language as hidden rejection
- keep block explicit
