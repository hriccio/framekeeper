# Version History Is Visible

Version history should remain visible enough that readers can understand how the
site changed.

## Meaning

Visibility does not mean clutter. It means the site should not hide the fact
that pages evolve and that earlier forms still matter.

## Related Episodes

- [Older Pages Still Matter](../episodes/014-older-pages-still-matter.md)
- [Archives Are Readable](../episodes/015-archives-are-readable.md)

## Notes

- keep the history understandable
- preserve context across edits
- do not force the site into a verbose changelog pattern
