## Core idea

Markdown is the source of truth for the knowledge layer.

---

## What I said

The site should remain easy to edit, easy to review, and easy to version. That
means the content that matters lives in markdown, not in a generated layer that
is harder to inspect.

---

## Key points

- markdown stays primary
- the site should be easy to change in Git
- generated output should not become the canonical record
