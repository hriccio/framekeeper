## Core idea

---

## What I said

There is no need to introduce custom hosting or extra infrastructure before the
manual content flow proves useful. The simple version is the one that can be
maintained consistently.

---

## Key points

- keep the hosting path simple
- avoid custom domain work until it is justified
- prefer a versioned default that is easy to reason about
