## Metadata

## Core idea

Episode pages should stay short enough to scan quickly.

---

## What I said

If an episode page is too long, it stops feeling like a structured memory of a
video and starts feeling like an unedited wall of text. The page should carry
the main idea, the supporting points, and the links that matter.

---

## Key points

- one page should cover one video
- the structure should stay easy to read
- detail belongs in links, not endless page length
