# Content Families Keep The Site Structured

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

---

## Core idea

The site stays easier to use when each content family has a clear job.

---

## What I said

Episodes, concepts, references, and notes are not the same kind of page. The
structure works because each one covers a different part of the knowledge
layer.

---

## Key points

- each family has a purpose
- structure makes the site easier to maintain
- the page families should not collapse into one generic page type
