# Titles Should Match The Idea

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

---

## Core idea

The title should match the idea the page is trying to carry.

---

## What I said

If a title promises one thing and the page says another, the reader loses trust.
The title is a promise about the page's content, not just a label.

---

## Key points

- titles should be honest
- titles should help readers predict the page
- titles should not oversell the content
