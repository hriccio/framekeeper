## Metadata

## Core idea

Featured links should stay selective so they keep their value.

---

## What I said

If everything is featured, nothing is featured. The small set of highlighted
pages should reflect what is most useful to a new reader or returning reader.

---

## Key points

- featured links need curation
- selectivity keeps the front door useful
- the feature set should not grow without reason
