# Broken Links Are Regressions

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

---

## Core idea

Broken links are regressions because they interrupt the site's reading path.

---

## What I said

If a link stops working, the page loses part of its value. The site should treat
that as a maintenance issue, not as a small cosmetic problem.

---

## Key points

- broken links break trust
- link integrity is part of maintenance
- the page should not become a debugging guide
