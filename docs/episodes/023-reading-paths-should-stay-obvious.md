# Reading Paths Should Stay Obvious

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

---

## Core idea

The route a reader should follow ought to be easy to see.

---

## What I said

Pages work better when the next step is obvious. The site should not force the
reader to guess where the supporting material lives.

---

## Key points

- the path should be visible
- supporting pages should be easy to find
- the page should not become a navigation manual
