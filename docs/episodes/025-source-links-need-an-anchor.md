# Source Links Need An Anchor

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

---

## Core idea

Source links are most useful when they clearly anchor a claim.

---

## What I said

If a reader cannot tell why a source is linked, the link is not doing enough
work. The page should make that relationship obvious.

---

## Key points

- every source link should answer a question
- the reader should know what the link proves or clarifies
- links without context are easy to ignore
