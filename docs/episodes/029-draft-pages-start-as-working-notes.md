## Core idea

Draft pages are working notes that are ready to be shaped into public content.

---

## What I said

The first version of a page does not need to be complete, but it does need to
be honest about being a draft.

---

## Key points

- drafts are intermediate artifacts
- working notes can become public pages later
- the page should still show editorial intent
