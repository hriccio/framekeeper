## Core idea

Sources stay useful when they are checked again instead of assumed to remain
current forever.

---

## What I said

An old source can still be valuable, but it should be revisited when the topic
is time-sensitive or when the external context may have changed.

---

## Key points

- sources age
- refresh cycles keep trust intact
- the site should not rely on stale external evidence
