## Core idea

A processing run should leave enough trace to understand what happened.

---

## What I said

The point of the run is not only to produce outputs. It is also to make the
steps visible enough that the result can be reviewed later.

---

## Key points

- runs should be inspectable
- the run is part of the repository's memory
- output alone is not enough if the path cannot be read
