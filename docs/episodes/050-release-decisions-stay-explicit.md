# Release Decisions Stay Explicit

## Metadata

- YouTube channel: `@umoutrohenrique`

## Core idea

Release needs a clear human decision, not an implied automation result.

## What I said

The repository should record release as a conscious judgment about whether the
current state is ready to leave the internal loop. That decision should stay
visible in the workflow.

## Key points

- release is explicit
- the human decision matters
- acceptance should be recorded before anything is exposed
