## Core idea

Feedback belongs after exposure, when the accepted state meets a real context.

## What I said

The repository should treat feedback as post-exposure evidence. That is where
real friction, surprise, and useful correction signals show up.

## Key points

- feedback comes after exposure
- it records real-context evidence
- it can reopen the loop for the next extract phase
