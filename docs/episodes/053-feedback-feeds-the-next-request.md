## Metadata

## Core idea

Feedback should inform the next request, not just sit in a log.

## What I said

Once exposure happens, the useful evidence should be turned into a new request
or a refinement of the old one. That keeps the loop alive instead of freezing
the outcome.

## Key points

- feedback can change the next request
- evidence should be captured explicitly
- the loop should remain open to refinement
