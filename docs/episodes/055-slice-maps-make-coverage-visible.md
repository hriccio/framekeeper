## Core idea

Slice maps show how request intent is covered by bounded build work.

## What I said

The map should make it easy to see what each slice covers and what evidence it
is expected to provide. That is useful for both build work and later review.

## Key points

- slice maps expose coverage
- the map should be explicit
- the map is traceability, not code
