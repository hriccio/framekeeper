# Transcript Fragments Need An Editorial Angle

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

## Core idea

A transcript fragment becomes useful when its editorial angle is visible.

## What I said

Not every interesting fragment should become the same kind of page. The angle
helps decide whether the fragment should become an episode, a concept, a
reference, or a note.

## Key points

- angle comes before drafting
- the fragment needs a clear purpose
- page shape follows the angle
