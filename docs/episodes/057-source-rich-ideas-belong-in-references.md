# Source-Rich Ideas Belong In References

## Metadata

- YouTube channel: `@umoutrohenrique`
- Status: refined

## Core idea

When an idea is mostly about a source, it belongs in a reference page.

## What I said

Some transcript-derived material is useful because it points to an external
source, policy, or article. That kind of material should be shaped as a
reference page instead of being forced into an episode or concept.

## Key points

- source-heavy ideas fit references
- the page should make the source easy to find
- the page should not become a general essay
