# Adding New Pages Workflow

## Purpose

This note records the workflow for adding new knowledge-layer pages.

## Notes

- create the page under the correct section first
- update the home page and section indices together
- keep the page manually authored and small
- add a test that proves the page exists and is linked
- keep raw evidence out of the published site
