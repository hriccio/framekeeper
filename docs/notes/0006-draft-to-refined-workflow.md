# Draft To Refined Workflow

## Purpose

This note records how content moves from draft to refined form.

## Notes

- draft pages are allowed to exist while ideas are still moving
- review should make the page clearer, not more abstract
- refined pages are the published ones
- the workflow should remain explicit and repeatable
