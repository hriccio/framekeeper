# Synchronizing Page Numbers

## Purpose

This note records how page numbers and indices stay in sync.

## Notes

- when a new page is added, the relevant index should be updated at the same time
- page numbers should remain consistent inside the current batch
- notes should help maintain the numbering rhythm without overcomplicating it
