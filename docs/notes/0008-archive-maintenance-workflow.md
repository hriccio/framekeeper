# Archive Maintenance Workflow

## Purpose

This note records how archived content is kept understandable.

## Notes

- older pages remain part of the knowledge layer
- archives should stay linked from the active site
- updates should preserve prior context instead of hiding it
- archival maintenance should not turn the site into a changelog
