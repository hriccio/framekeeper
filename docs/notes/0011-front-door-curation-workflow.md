# Front Door Curation Workflow

## Purpose

This note records how the home page and featured links are curated.

## Notes

- the home page should stay selective
- featured links should represent the strongest entry points
- new pages should be evaluated before being promoted to the front door
- the note should not become a page inventory checklist
