# Reference Review Workflow

## Purpose

This note records how references are reviewed before they are linked.

## Notes

- confirm the source actually supports the claim
- prefer the smallest set of links that explains the point
- keep the page readable after the links are added
- avoid turning reference sections into archives of everything found
