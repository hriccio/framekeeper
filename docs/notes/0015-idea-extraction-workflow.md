# Idea Extraction Workflow

## Purpose

This note records how ideas are extracted from transcripts into draft
candidates.

## Notes

- read the transcript for candidate ideas
- separate reusable ideas from one-off phrasing
- capture the idea in a draft page or note
- refine the draft into the appropriate page family
