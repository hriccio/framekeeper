# Safety Tier Workflow

## Purpose

This note records how `REVIEW` and `BLOCK` behave in the safety path.

## Notes

- use `REVIEW` when the content needs human attention
- use `BLOCK` when the workflow must stop
- keep any override explicit
- preserve the difference between a pause and a stop
