# Repository Memory Workflow

## Purpose

This note records how the repository stores raw evidence and change history.

## Notes

- keep original source material in `work/sources`
- keep request and implementation artifacts in `work/changes`
- let the published knowledge layer stay refined
- preserve the loop so later work can understand earlier decisions
