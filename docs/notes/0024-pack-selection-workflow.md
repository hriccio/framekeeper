# Pack Selection Workflow

## Purpose

This note records how the selected pack is chosen and documented.

## Notes

- choose a pack that matches the implementation shape
- make the pack explicit in architecture and structure guidance
- keep the pack separate from MRL core
- update the repository decisions when the pack changes
