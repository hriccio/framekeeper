# Scenario Evaluation Workflow

## Purpose

This note records the practical workflow for scenario evaluation in the MRL
loop.

## Notes

- run a deterministic scenario
- capture the relevant evidence
- review the packet with the evaluation model
- decide whether the request needs refinement
