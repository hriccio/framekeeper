# Feedback Capture Workflow

## Purpose

This note records how post-exposure feedback is captured and used in the next
MRL loop.

## Notes

- observe what happened in the real context
- record surprises, friction, and drift
- turn those observations into the next request or refinement
- keep the evidence separate from signal scoring
