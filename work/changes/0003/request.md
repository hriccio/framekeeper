## Request Boundary

Seed the knowledge layer with the first real content pages:

```text
home page -> one episode page -> one concept page -> one reference page
```

The request is to make the site feel like an actual knowledge layer, not only a
navigation shell, while keeping the content markdown-first and manually authored.

## Success Expectations

- at least one episode page exists beyond the template
- at least one concept page exists beyond the index
- at least one reference page exists beyond the index
- the home page links to the seeded content
- the section indices list the seeded content
